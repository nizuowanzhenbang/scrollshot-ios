# 轻卷截图

面向 iOS 18 的原生滚动长截图应用。目标手机是 iPhone 16 Pro / iOS 18.7.8；当前为 0.3.0 预览版。0.1.1 的实际采集已由用户确认，后续新功能仍需目标手机验收。

## 标准版安装包

当前仅构建标准版（0.3.0 build 6），不再生成录屏导入版。系统确认开始采集后，切到其他 App 滚动，停止后返回自动拼接。

IPA 使用 ad-hoc 签名以保留包结构，需要用有效证书重新签名才能安装到真实 iPhone。签名时必须保留 Broadcast 扩展，主程序与扩展须具有一致且获描述文件授权的 App Group。详细签名要求见 [中文说明中的标准版部分](docs/全能签安装.md#标准版)。

预览页右下角的“复制”将当前完整 PNG（包括已应用的裁剪、马赛克）写入剪贴板，分段时按顺序复制多张；接收应用可能只粘贴第一张。复制不会先将整张长图解码为位图，也不会写入相册。

## 0.1.1 签名兼容修复

标准版会读取主程序和录屏扩展各自描述文件中的共享组元数据，优先使用构建组，其次按固定顺序选择双方共同授权且系统允许当前进程访问的组。应用不会因为修改配置就获得额外权限。元数据读取不代替签名验证，容器访问仍由系统检查。

录屏按钮使用安装包内实际扩展标识；缺少扩展或标识不匹配时，“采集检查”会显示具体情况。共享组适配通过也不代表系统已在控制中心接受该扩展，仍需真实手机验证。

## 已实现

- 草稿与作品在首页第一组，显示最新 5 个；“更多草稿”查看全部，右滑显示删除按钮并确认，正在采集的草稿禁止删除。
- 设置集中管理自动/浅色/深色外观、停滑自动停止、智能去除滚动条、开始/停止震动、可修改的 20 MB 大图保存提醒。
- 全屏“工具”进入马赛克与裁剪：浏览定位后框选，绿色框为裁剪范围，灰块为马赛克区域；支持四边像素裁剪和撤销，应用后查看实际像素结果。
- PNG 按条带生成，同时生成不超过 512 行的精确预览图块。原始帧保留，图片编辑参数可重新调整。
- 手动压缩和大图保存询问共用压缩流程：JPEG 最大宽度 1080、每张最多 8000 行，保留原始 PNG，只有实际变小时才提交压缩版。
- 标准版停滑自动停止：默认开启、3 秒，可保存任意有限正数秒数（含小数），也可关闭；下一次录屏生效。
- 首次检测到竖向滚动后开始计时；独立计时器处理静止画面不再回调的情况，停止前保存尾帧。
- 返回应用自动全屏展示刚完成的长截图，右下角悬浮按钮保存 PNG 到相册；关闭后的旧结果不会反复弹出。
- ReplayKit 视频帧采样，最多 5 次分析/秒，使用小图进行重叠测量。
- 正反向位移累计、重复覆盖抑制、不可靠重叠分段、可恢复草稿。
- 原尺寸 JPEG 中间帧；导出 PNG 保持采集宽度，中间 JPEG 有压缩。
- 调整每帧的固定顶底栏，以及最终边界裁剪。
- 按 64 行条带导出，单张超过 60,000 行时分图。
- 相册/文件录屏导入、缩略分段预览、相册添加和文件分享。
- 所有图像处理在本机执行，不含账号、广告或远端处理服务。

## 当前限制

- 首版面向竖屏、向下匀速滚动。跳过整屏、过快滚动、大片动画或低纹理画面可能无法连续拼接，此时分别输出片段。
- 不能录制受系统保护的内容。录屏授权使用 iOS 系统界面。
- 默认顶底栏裁剪只是建议；可调为 0 后重新生成，原始采集帧仍保留。
- 未经目标真机计时前，不承诺 10 屏 5 秒的性能目标已经达到。
- 原始草稿保留在应用存储中，重新生成成功后清理旧结果；使用前留出足够空间。
- 停滑依据屏幕画面位移判断，无法读取其他应用中的手指触摸。动画、视频、快速跳页可能延迟停止；实际停止时间受采样、约 100 毫秒的定时检查及系统调度影响。为避免在 5 Hz 采样的间隙误停，小于 0.3 秒的设置按 0.3 秒检测，输入值仍会保留。
- 尚未滚动时不会开始自动停止计时。暂停/恢复录屏后须再次滚动才开始计时。停止会使用 ReplayKit 的公开结束接口，可能显示系统结束提示。
- 自动全屏在你切回应用后触发；生成中显示进度，不会强制把后台应用切到前台。悬浮按钮支持保存所有分段，过长内容仍按原规则分图。
- 智能去除滚动条只填补右边缘识别出的窄条区域，复杂背景可能无法识别；开关在下一次生成时生效。重新拼接会清除图片裁剪/马赛克，请在最终拼接后编辑。
- 震动通过公开 Audio Services API 在录屏开始、结束时请求，使用一次性门控避免自动停止与结束回调重复触发。模拟器不能证明后台扩展实际震动；系统是否响应需在真机确认。

## 本地构建（Mac）

依赖 Xcode 16.4 或支持 iOS 18 部署目标的后续版本、Swift、Python 3 和 XcodeGen。使用系统框架与系统 zlib，没有第三方运行时 SDK。

```bash
swift test
python3 -m unittest discover -s scripts -p test_verify_ipa.py -v
bash scripts/build.sh
bash scripts/simulator-smoke.sh
```

输出位于 `build/ScrollShot-standard-0.3.0.ipa`。`APP_GROUP_ID` 可在构建前设置，必须与实际签名授权一致。

## 结构

- `Core/`：灰度匹配、连续覆盖计划、草稿、视频解码、PNG 条带导出。
- `App/`：SwiftUI 界面、相册选取/保存、系统分享。
- `Broadcast/`：ReplayKit Upload 扩展。
- `Tests/`：真实像素/文件/视频测试。
- `Tools/FixtureGenerator/`：仅供模拟器验收的合成草稿工具，不打入应用。
- `scripts/`：打包、负例校验和模拟器验收。

公开仓库只包含本次新实现，不包含作为分析参考的第三方 IPA、解包二进制、签名材料或用户图像。验收边界见 [真机清单](docs/真机验收.md)。
