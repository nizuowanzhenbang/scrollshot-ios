# 标准版 build 6：预览复制

长截图全屏预览右下角，“保存相册”旁增加“复制”。复制当前完整 PNG，包含已应用的裁剪、马赛克和滚动条处理，不使用屏幕缩略预览或 JPEG 压缩副本。分段结果按输出顺序一次写入剪贴板；接收应用可能只支持粘贴第一张。

复制时禁止重复点击及同时编辑、删除、保存；失败或取消不会主动清空旧剪贴板。文件在后台读取，直接提交 PNG 数据，避免完整长图位图解码。成功显示“已复制到剪贴板”，多张时显示张数，3 秒后恢复按钮文字。

真机验收：

1. 生成长截图，在预览点“复制”，切到微信或备忘录粘贴，确认是完整图片而非文字、文件路径或当前可见部分。
2. 应用裁剪、马赛克后再次复制，确认粘贴图片与当前预览及保存 PNG 一致。
3. 测试多片段草稿，核对成功提示张数及接收应用的支持情况。
4. 复制一张较长图片，确认按钮处理期间不可重复点击；关闭预览或切后台后，重开仍可再次复制。

本次构建仅生成标准版。工程、打包脚本及后续模拟器脚本均已改用标准版目标；不再构建录屏导入版。不创建正式 Release，真机粘贴行为由用户验收。
