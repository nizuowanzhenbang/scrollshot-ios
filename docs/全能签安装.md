# 全能签安装与使用

## 选择版本

- **Standard 标准版**：可直接从应用启动跨 App 录屏采集，但签名必须正确支持录屏扩展和 App Groups。
- **Import 录屏导入版**：不包含录屏扩展和 App Groups，适合先验证安装和拼接；先用 iOS 自带录屏，再导入视频。

两个版本的 Bundle ID 不同，可以同时安装。IPA 需要重新签名；构建时的 ad-hoc 签名不能直接授权真实 iPhone 运行。

## 导入版

1. 把 `ScrollShot-import-0.1.0.ipa` 保存到手机“文件”中。
2. 在全能签中导入 IPA，使用你已有的有效证书与描述文件签名并安装。不同版本工具的按钮名称可能不同。
3. 如果系统要求信任开发者或开启开发者模式，按相应系统提示完成。
4. 使用控制中心的系统录屏，在目标 App 中竖向匀速滚动，停止后确认视频已保存到相册。
5. 打开“轻卷截图·导入”，点击“从相册选择”，选中该录屏；也可以从“文件”导入。
6. 等待本机处理。应用自动生成结果；若分为多张，说明检测到多个连续片段或超出单张高度限制。
7. 有固定顶栏/底栏时调整裁剪，点击重新生成；通过“保存相册”或“分享文件”取出 PNG。

## 标准版

构建标识：

```text
主程序：com.nizuowanzhenbang.scrollshot
扩展：com.nizuowanzhenbang.scrollshot.Broadcast
共享组：group.com.nizuowanzhenbang.scrollshot
```

1. 导入 `ScrollShot-standard-0.1.0.ipa`。
2. 签名时保留 `PlugIns/BroadcastExtension.appex`；不要通过移除插件来消除签名错误。
3. 主程序与扩展使用同一开发团队。二者的 `com.apple.security.application-groups` 必须一致，并得到各自描述文件授权。
4. 首次安装保留上述构建标识；若改标识，需同步核对主程序配置、扩展 Bundle ID、共享组和授权配置。
5. 打开应用，看“开始滚动截图”是否可用。如果显示共享权限自检失败，先使用导入版，或修正签名配置。
6. 点击录屏按钮，使用系统确认界面开始，倒计时期间切到目标 App。
7. 向下匀速滚动，避免一次跳过整屏内容；通过系统入口停止录屏，再回到“轻卷截图”。
8. 自动处理后检查接缝和裁剪，再保存或分享。

全能签是签名工具，所用描述文件才决定允许声明哪些权限。仅在 IPA 内添加 App Groups 字符串不能获得系统授权。参考 [Apple：描述文件授权规则](https://developer.apple.com/documentation/technotes/tn3125-inside-code-signing-provisioning-profiles)。

## 常见情况

- **安装失败/闪退**：核对证书、有效期、设备授权、主程序/扩展及共享权限；先尝试不含扩展的 Import 版，以区分签名与采集配置。
- **画面分成多个片段**：减少滚动速度；避免跳页、横竖屏切换、全屏动画和一次越过整屏内容。
- **重复顶栏/底栏**：增加每帧相应裁剪；原始帧保留，可重新生成。
- **裁掉内容**：减小建议裁剪值，必要时改为 0。
- **异常停止后仍显示采集中**：确认系统录屏已停止，等待至少 10 秒，再在草稿中选择恢复。
- **相册保存不成功**：检查相册添加权限；已有 PNG 仍可用“分享文件”取出。

建议先用非敏感的普通文字页面完成一次安装、生成、保存测试，再使用实际内容。
